\title{Full Hessian of a smaller svGPFA model}
\author{Joaqu\'{i}n Rapela\thanks{j.rapela@ucl.ac.uk}}

\begin{document}

\maketitle

We fitted a smaller svGPFA model (5 trials, 3 latents, 5 inducing points
locations, and 50 neurons) to behavioral trials 42-46 from Emmett's recordings.
The model contained 586 parameters (Figure~\ref{fig:nParams}).
We then calculate the full Hessian of the model parameters, to check the
interaction between different groups of parameters (variational mean, Cholesky
representation of the variational covariance, C matrix, d vector, kernel
parameters, inducing points locations). If the off-diagonal elements of the
Hessian corresponding to different groups of parameters are small, then an
Expectation Constrained Maximisation approach is sensible. Otherwise, the
simultaneous optimisation of all svGPFA parameters should work better.

Figure~\ref{fig:lowerBoundVsIteration} plots the achieved lower bound as a
function of the number of iterations. This figure does not show problems in the
estimation.
